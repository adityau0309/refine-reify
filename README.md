# Premium Polish Pass

website link on which below operation needs to be performed:https://recify-ar.lovable.app/

Do a full structural and visual polish pass across the entire site (Home, System, Services, Industries, Pricing, Results, About, FAQ, Contact, Start, Security). Do NOT change the color palette, brand voice, copy, or overall theme — this is purely a layout, spacing, alignment, and structural refinement pass to make the site feel like a large, premium brand's website rather than a first draft.

═══════════════════════════════

1. GLOBAL SPACING SYSTEM

═══════════════════════════════

- Apply one consistent vertical rhythm site-wide: define a single spacing scale (e.g. 24px / 48px / 80px / 120px) and use it consistently for section padding, element gaps, and margins across every page — no page should feel more cramped or more sparse than another.

- Eliminate large dead/empty areas anywhere on any page (especially below hero sections). Every section should feel intentionally composed — if a section is content-light, reduce its vertical padding to match its content rather than leaving excess white space.

- Ensure consistent horizontal container width and side padding across all pages so content doesn't shift width from page to page.

═══════════════════════════════

2. CTA SIZING & HIERARCHY

═══════════════════════════════

- Standardize all CTA buttons to one consistent size/padding/border-radius system site-wide: primary (solid/filled) and secondary (outline or text-link) styles should look identical in treatment wherever they appear — nav, hero, mid-page, footer.

- Reduce any oversized CTA buttons currently taking disproportionate visual weight relative to surrounding text.

- Where two CTAs appear together (e.g. "Get free AR health check" + "See how it works," or the final "Get your free AR health check" + "Book an AR fit call"), ensure clear visual hierarchy — one primary/filled, one secondary/outlined — so it's obvious which action is the main one, not two competing equal-weight buttons.

═══════════════════════════════

3. ALIGNMENT & GRID CONSISTENCY

═══════════════════════════════

- Audit every page for consistent alignment of headlines, body copy, buttons, and supporting text within their columns — nothing should appear visually offset from adjacent elements.

- Ensure all card-based sections (service cards, pricing tiers, industry cards, "Recover/Resolve/See" blocks, comparison table rows) have equal height, equal internal padding, and identically positioned internal elements (icon, heading, body text, CTA all aligned at the same vertical position across every card in a row).

- Apply a consistent grid/column system across the site so text blocks and images line up predictably page to page, not eyeballed per-section.

═══════════════════════════════

4. HERO VIDEO

═══════════════════════════════

- Fix the hero video container so it blends into the page rather than sitting as a hard-edged box: match surrounding background color at the video's edges, or apply a soft gradient/fade mask at the boundary so there's no visible hard rectangle.

- Ensure the video is properly responsive and doesn't break proportions or crop awkwardly on smaller screens.

- Confirm autoplay, loop, muted, and no visible player controls across all breakpoints.

═══════════════════════════════

5. LOGO

═══════════════════════════════

- Replace the current icon+wordmark logo across the entire site (nav, footer, favicon references) with a clean wordmark-only treatment: "recify." in the existing bold lowercase brand font, no icon/symbol beside it.

- Ensure appropriate left-margin spacing around the wordmark in the nav bar so it doesn't sit flush against the edge.

- Generate a simple favicon: lowercase "r" in bold, centered on a solid brand-color (navy or slate-blue) square background, legible at 16x16px.

═══════════════════════════════

6. TYPOGRAPHY CONSISTENCY

═══════════════════════════════

- Apply one consistent type scale site-wide: one size/weight for H1 (page headlines), one for H2 (section headlines), one for H3 (card/sub-headlines), one for body text, one for small/label text (like "01 Managed AR" numbering or eyebrow text). Apply identically across every page rather than varying per-section.

- Ensure consistent line-height and letter-spacing so text density feels uniform throughout the site.

═══════════════════════════════

7. COMPARISON TABLE & STRUCTURED SECTIONS

═══════════════════════════════

- Clean up the "Traditional software vs. Recify" comparison section so each row is clearly aligned in a proper two-column table structure with consistent row height and spacing — not free-floating text pairs.

- Apply the same alignment discipline to the "AI handles the volume / People handle the judgment" two-column section and the "How it works" 4-step section — consistent spacing between numbered steps, aligned icon/number/heading/body positioning throughout.

═══════════════════════════════

8. PRICING SECTION

═══════════════════════════════

- Ensure all three pricing tier cards are equal width, equal height, with the "Recommended" tier visually distinguished (subtle highlight/border) but not disproportionately larger or oddly positioned relative to the other two.

- Align price, tagline, and CTA button position identically across all three cards.

═══════════════════════════════

9. MOBILE RESPONSIVENESS

═══════════════════════════════

- Re-verify every fix above holds up correctly at mobile breakpoints (375px-428px): single-column stacking for multi-column sections, proportional text scaling with clean line-wrapping (no headline wrapping awkwardly at 2-3 words per line), touch-friendly button sizing (minimum 44x44px tap targets), no horizontal overflow anywhere on any page.

- Specifically re-check the pricing cards, comparison table, and "Recover/Resolve/See" service blocks on mobile — these are the sections most likely to break into illegible or cramped layouts on small screens.

═══════════════════════════════

10. FINAL CONSISTENCY PASS

═══════════════════════════════

- Remove any mismatched border-radius values, inconsistent shadow styles, or leftover placeholder styling so every button, card, and section feels like it belongs to one unified design system.

- Confirm consistent footer structure and spacing across all pages.

- Do a final check that no section anywhere has more than one full "empty screen" of white/cream space with no content — this is the most visible sign of an unfinished page.

Goal: preserve all existing copy, colors, and content exactly as-is — only refine spacing, alignment, sizing, and structural consistency so the site reads as a cohesive, professionally polished, premium B2B brand site ready to publish.
