# Recify Marketing Reel

A 20-second, 1080x1920 vertical Remotion composition focused on the message **Revenue is not cash**.

## Run locally

```bash
cd video
npm install
npm run start
```

Open the `RecifyMarketing` composition in Remotion Studio.

## Render MP4

```bash
npm run render
```

Output: `video/out/recify-marketing.mp4`

The project uses Remotion 4.0.517, matching the version currently published by the Remotion repository.
